# 문제 해결

[English](troubleshooting.md)

## 편집기가 실행되지 않아요

- **"Windows의 PC 보호"라는 파란 창이 떠요.** 아직 코드 서명을 받지 않은 프로그램이라 나오는 안내입니다. **추가 정보**를 누른 뒤 **실행**을 누르세요.
- **실행하자마자 꺼지거나 DLL 오류가 나요.** zip 안의 파일을 모두 같은 폴더에 두었는지 확인하세요. `effect_video.exe`만 따로 옮기면 실행되지 않습니다. 압축을 풀지 않고 zip 안에서 바로 실행해도 안 됩니다.

## AI가 편집기를 모른다고 해요

AI가 "그런 도구가 없다", "AI Effect Video에 접근할 수 없다"고 한다면 연결 설정이 적용되지 않은 것입니다.

1. 설정을 바꾼 뒤 AI 프로그램을 **완전히 종료했다가** 다시 실행했는지 확인하세요. 트레이에 남아 있으면 설정을 다시 읽지 않습니다.
2. 설정 파일의 경로가 실제 `effectvideo-mcp.exe` 위치와 같은지 확인하세요. 폴더를 옮겼다면 경로도 고쳐야 합니다. `EffectVideo-1.0.0`이라는 폴더 안에 압축을 풀었다면 프로그램이 한 겹 더 안쪽(`...\EffectVideo-1.0.0\EffectVideo-1.0.0\`)에 있을 수 있습니다.
3. Claude Desktop·VS Code 설정(JSON)에서는 `\`를 `\\`로 두 번 썼는지 확인하세요.
4. ChatGPT라면 데스크톱 앱의 **Work** 모드인지 확인하세요. **Chat** 모드와 웹사이트에서는 쓸 수 없습니다.

## AI가 오류를 알려 줘요

AI가 아래 단어가 들어간 오류를 말하면 다음처럼 하세요.

| 오류 | 뜻 | 이렇게 하세요 |
|---|---|---|
| `not_connected` | 편집기에 연결하지 못했습니다 | 편집기를 직접 실행하고, **설정 › AI 연결 허용 (MCP)** 이 켜져 있는지 확인하세요 |
| `connection_lost` | 작업 중에 편집기가 닫혔습니다 | 편집기를 다시 실행한 뒤 AI에게 다시 부탁하세요 |
| `timeout` | 편집기가 1분 안에 답하지 않았습니다 | 편집기에 열린 창(저장 확인 등)이 있으면 닫고 다시 부탁하세요. 그 부탁은 실행되지 않았습니다 |
| `busy` | 내보내기가 진행 중입니다 | 끝날 때까지 기다리거나 "내보내기 취소해 줘"라고 하세요 |
| `unsaved_changes` | 저장하지 않은 작업이 있습니다 | 저장할지 버릴지 AI에게 알려 주세요 |
| `file_exists` | 같은 이름의 파일이 이미 있습니다 | 덮어써도 되는지, 다른 이름으로 할지 AI에게 알려 주세요 |
| `missing_media` | 프로젝트에 쓰인 영상 파일이 다른 곳으로 옮겨졌습니다 | 지금 파일이 있는 위치를 AI에게 알려 주세요 |
| `no_source` | 아직 영상을 열지 않았습니다 | 먼저 열 영상 파일을 알려 주세요 |
| `clip_too_long` | 확인용 파일을 만드는 데 너무 오래 걸렸습니다 | 구간을 짧게 나눠 부탁하거나, "내보내기"로 만들어 달라고 하세요 |

그 밖의 오류는 [도구 설명서의 오류 목록](tools.md#error-codes)(영어)에 있습니다.

## 다른 프로그램과 충돌해요 (고급)

편집기는 이 PC 안에서 9877번 포트로 AI와 연결합니다. 다른 프로그램이 이미 이 번호를 쓰고 있으면 연결되지 않습니다. 이때는 환경 변수 `EFFECTVIDEO_MCP_PORT`로 다른 번호를 정하세요. 편집기와 AI 프로그램 설정 양쪽에 같은 번호를 줘야 합니다. [다른 AI 프로그램에 연결하기](../examples/other-clients.ko.md#고급-환경-변수)를 보세요.

## 로그 파일

편집기의 **도움말 › 로그 저장…** 으로 문제 상황이 기록된 파일을 저장할 수 있습니다. 문의할 때 함께 올려 주세요. 로그는 `%LOCALAPPDATA%\EffectVideo\logs` 폴더에도 남습니다.

## 그래도 해결되지 않으면

[GitHub Issues](https://github.com/NexCreDesign/ai-effect-video-mcp/issues)에 다음을 함께 올려 주세요.

- 편집기 버전 (**도움말 › AI Effect Video 정보…**)
- 쓰는 AI 프로그램 (예: Claude Desktop, ChatGPT 데스크톱 Work)
- AI에게 부탁한 말과 AI가 보여 준 오류 문구
- 로그 파일
