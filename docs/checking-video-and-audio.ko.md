# AI가 결과를 확인하는 방법

[English](checking-video-and-audio.md)

AI는 영상을 재생해서 보거나 소리를 들을 수 없습니다. 그래도 편집 결과를 꽤 정확히 점검할 수 있습니다. 이 문서는 AI가 무엇을 볼 수 있는지, 어떻게 부탁하면 좋은지 설명합니다.

## AI가 볼 수 있는 것

| 확인할 것 | AI가 받는 것 |
|---|---|
| 지금 화면 | 편집 결과 한 장면을 사진으로 |
| 움직임, 페이드, 장면 전환 | 정한 구간에서 고르게 뽑은 사진 여러 장 (최대 16장) |
| 작은 글자나 세부 | 화면 일부를 크게 확대한 사진 |
| 소리가 나는지, 크기, 페이드 | 구간을 20칸으로 나눈 소리 크기 숫자와 파형 그림 |
| 영상 파일 자체 | 구간을 mp4 파일로 만들어 그 위치를 알려 줌 (사람이 직접 재생해 보는 용도) |

## 이렇게 부탁해 보세요

> 1분 20초부터 1분 40초까지 확인해 줘. 글자가 언제 나오는지, 페이드가 자연스러운지, 소리가 끊기는 곳이 있는지 봐 줘.

> 3초 부근 오른쪽 위 글자가 잘리지 않았는지 확대해서 봐 줘.

> 마지막 5초 소리가 점점 작아지는지 확인해 줘.

> 10초부터 15초까지 mp4로 만들어 줘. 내가 직접 볼게.

AI는 보통 이런 순서로 확인합니다.

1. 말한 시각을 정확한 프레임 번호로 바꿉니다.
2. 구간을 작은 사진 여러 장으로 훑어봅니다.
3. 이상해 보이는 곳만 범위를 좁혀 다시 봅니다.
4. 필요하면 일부를 확대해서 봅니다.
5. 소리는 크기 숫자로 확인합니다.

## 한계

- **소리 내용은 모릅니다.** AI는 소리의 크기만 잴 수 있고, 무슨 말이나 음악인지는 알 수 없습니다.
- **시점이 조금 어긋날 수 있습니다.** 소리는 구간을 20칸으로 나눠 재기 때문에, 긴 구간에서는 "언제 시작하는지"가 0.1~0.2초쯤 어긋날 수 있습니다. 정확히 알고 싶으면 "그 부분만 좁혀서 다시 확인해 줘"라고 하세요.
- **사진이 많으면 대화가 빨리 길어집니다.** 사진은 대화 용량을 많이 씁니다. 긴 영상 전체보다 확인할 구간을 정해서 부탁하는 편이 좋습니다.
- **만든 파일은 하루 뒤 지워집니다.** 저장 위치를 말하지 않으면 확인용 파일은 임시 폴더에 만들어지고 하루 뒤 지워집니다. 남겨 둘 파일은 "D:\check\a.mp4로 만들어 줘"처럼 위치를 말해 주세요.

## 고급

### 소리 숫자 읽는 법

AI가 보여 주는 숫자의 뜻입니다.

- `peak_db`, `rms_db`: 소리 크기(dB). 0이 가장 크고, `-120`은 소리가 없음입니다.
- `silent_percent`: 구간 중 거의 들리지 않는(-60dB보다 작은) 부분의 비율
- `levels`: 구간을 20칸으로 나눈 각 칸의 크기. 페이드 아웃이면 숫자가 점점 작아집니다.
- `clipped_samples`: 0보다 크면 소리가 너무 커서 찌그러지는 부분이 있다는 뜻입니다.

### 파일 내용을 대화로 보내는 옵션 (`embed`)

AI가 만든 mp4나 WAV 파일 내용을 대화에 직접 실어 보내는 옵션이 있지만, 대부분의 AI 프로그램은 이를 제대로 처리하지 못합니다. Codex 같은 일부 프로그램은 내용을 글자로 바꿔 넣어 대화가 순식간에 가득 찹니다(2초 영상이 약 1MB의 글자가 됨). AI도 기본으로 쓰지 않으니 따로 요청하지 마세요.

### 긴 구간 자동 검사 (ffmpeg가 있을 때)

PC에 ffmpeg가 설치되어 있고 AI가 명령을 실행할 수 있다면(Claude Code, Codex 등), AI가 만든 mp4 파일에서 장면 전환·검은 화면·무음을 자동으로 찾게 할 수 있습니다. ffmpeg는 편집기에 들어 있지 않습니다.

```
ffmpeg -hide_banner -i clip.mp4 -vf "select='gt(scene,0.3)',metadata=print:file=-" -an -f null -
ffmpeg -hide_banner -i clip.mp4 -vf blackdetect=d=0.1:pix_th=0.1 -an -f null -
ffmpeg -hide_banner -i clip.mp4 -af silencedetect=n=-50dB:d=0.5 -vn -f null -
```

찾은 시각은 `clip.mp4` 처음부터 잰 값이라, 편집기의 시각으로 바꾸려면 클립의 시작 위치를 더해야 합니다. AI에게 "찾은 곳을 편집기 화면에서 다시 확인해 줘"라고 하면 됩니다.

### 다른 AI 서비스에 영상 보내기

영상 파일을 직접 받아 분석하는 AI 서비스도 있지만, 그러면 파일이 내 PC 밖으로 나갑니다. 영상 내용을 보고 판단하세요.
